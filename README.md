# NIJOK Premium — GitHub Pages website

A responsive, multi-section luxury editorial website built with plain HTML, CSS and JavaScript. No framework, package install or build step is required.

## Publish on GitHub
1. Extract `nijok-premium.zip` on your computer.
2. Open your GitHub repository and upload `index.html`, `styles.css`, `script.js`, the `assets` folder and this README (upload the files inside the folder, not the ZIP itself).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

## Included
- Home page with a large editorial hero model image
- Separate full-page views for Fashion, Jewellery, Models, Automobiles, Lifestyle, Designers and Stories
- Minimal navigation, responsive mobile menu and working search panel
- Original generated hero image stored locally in `assets/hero-model.png`

## Notes
- The category/story photographs are loaded from Unsplash URLs and therefore require an internet connection.
- This is a visual editorial concept/demo. Replace placeholder editorial copy, images and brand/legal details before commercial launch.
- The hero model is a newly generated editorial image inspired by the reference mood, not a copy of a real person's photograph.
